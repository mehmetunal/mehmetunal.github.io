Privacy Policy

Last updated: 7 September 2026

Unal Agent is a Visual Studio Code extension by Mehmet Ünal / Maggsoft. It helps you write and fix code in natural language. We respect your privacy.

Summary

Unal Agent does not run a Maggsoft account or backend for this product. API keys stay on your machine. Project files go only to the model you choose: a local runtime stays on-device; a cloud model is sent to that provider.

Data stored on your device

  • API keys: OS keychain or ~/.unal-agent/secrets.json (restricted file permissions). They are not written to git or VS Code settings.json.
  • Settings and sessions: model choice, chat history, and optional project memory under ~/.unal-agent and the project’s .unal/ folder.

Data sent to a model

  • Your chat text, attached files, and workspace content the agent reads are sent to the selected LLM.
  • Local model (Ollama, LM Studio, llama.cpp, vLLM): the request stays on this machine.
  • Cloud provider (OpenAI, Google, NVIDIA, Azure OpenAI, or a custom endpoint): the request is subject to that provider’s privacy policy. Unal Agent does not sell a model subscription.
  • Password and private-key files (.env, *.pem, id_rsa, and similar) are not sent to the model.

Data we do not collect

  • No Maggsoft analytics, ads, or account system.
  • No payment card data.
  • No location, contacts, camera, or microphone.

Third parties

  • Visual Studio Marketplace — extension distribution (Microsoft)
  • The LLM provider you choose — only when you use a cloud model
  • Optional Hugging Face GGUF search — model catalogue; project source is not uploaded

Children

The product is for software developers. We do not knowingly collect personal data from children under 13.

Changes
