FAQ

  • Is Mag AI free? The extension installs from the Marketplace. Model usage is billed to your account (or runs on your machine).
  • Where is the API key stored? OS keychain or ~/.mag-ai — not settings.json or git.
  • Will it edit the wrong file? Default permission asks before every write and command. Plan and Ask never write files.
  • Local model? If Ollama, LM Studio, llama.cpp, or vLLM is running: Settings → Local models.
