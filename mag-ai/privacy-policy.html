Gizlilik Politikası

Son güncelleme: 7 Eylül 2026

Mag AI, Mehmet Ünal / Maggsoft tarafından geliştirilen bir Visual Studio Code eklentisidir. Konuşarak kod yazmanıza ve düzeltmenize yardımcı olur. Gizliliğinize saygı duyuyoruz.

Özet

Mag AI bir hesap veya Maggsoft sunucusu işletmez. API anahtarlarınız cihazınızda saklanır. Proje dosyalarınız yalnızca seçtiğiniz modele gider: yerel modelde makinede kalır; bulut modelde ilgili sağlayıcıya iletilir.

Cihazda saklanan veriler

  • API anahtarları: işletim sistemi parola kasası veya ~/.mag-ai/secrets.json (dosya izinleri kısıtlı). Git’e veya VS Code settings.json dosyasına yazılmaz.
  • Ayarlar ve oturumlar: model seçimi, sohbet geçmişi ve isteğe bağlı proje hafızası ~/.mag-ai ve proje .magai/ altında.

Modele giden veriler

  • Sohbet metniniz, eklediğiniz dosyalar ve ajanın okuduğu proje içeriği, seçili LLM’e gönderilir.
  • Yerel model (Ollama, LM Studio, llama.cpp, vLLM): istek bu makinede kalır.
  • Bulut sağlayıcı (OpenAI, Google, NVIDIA, Azure OpenAI veya özel uç): istek o sağlayıcının gizlilik politikasına tabidir. Mag AI sizin adınıza bir model aboneliği satmaz.
  • Parola ve özel anahtar dosyaları (.env, *.pem, id_rsa ve benzeri) modele verilmez.

Toplanmayan veriler

  • Maggsoft analitik, reklam veya hesap sistemi yoktur.
  • Ödeme kartı bilgisi toplanmaz.
  • Konum, rehber, kamera veya mikrofon kullanılmaz.

Üçüncü taraf hizmetler

  • Visual Studio Marketplace — eklenti dağıtımı (Microsoft)
  • Seçtiğiniz LLM sağlayıcısı — yalnızca bulut model kullandığınızda
  • İsteğe bağlı Hugging Face GGUF araması — model kataloğu, proje kodu yüklenmez

Çocuklar

Ürün yazılım geliştiricilere yöneliktir. Bilerek 13 yaş altından kişisel veri toplanmaz.

Değişiklikler
